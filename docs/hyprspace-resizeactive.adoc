= hyprspace-resizeactive(1)
include::util/man-attributes.adoc[]
// tag::purpose[]
:manpurpose: Resize the focused window by the given amount of pixels
// end::purpose[]
:manname: hyprspace-resizeactive

// =========================================================== Synopsis
== Synopsis
[verse]
// tag::synopsis[]
hyprspace resizeactive [-h|--help] [--window-id <window-id>] [exact] <x> <y>

// end::synopsis[]

// =========================================================== Description
== Description

// tag::body[]
{manpurpose}.

`<x>` changes the width, `<y>` changes the height. Negative numbers shrink the window. Zero keeps the dimension as is.

With `exact`, `<x>` and `<y>` are the new width and height instead of the difference.

Floating windows are resized directly. With `exact`, their size can also be a percentage of the monitor: `resizeactive exact 50% 50%`.
Tiling windows are resized by changing the weights of the tiles.
// end::body[]

// =========================================================== Options
include::util/conditional-options-header.adoc[]

-h, --help:: Print help
--window-id <window-id>:: Act on the specified window instead of the focused window
